01Introduction

TT-PHALYX is a 16-pad drum and loop sampler implemented as a REAPER JSFX instrument. Each pad plays two sample slots (A and B) with a crossfade, and offers per-pad sound shaping — transpose, filter, envelopes, loops — plus a per-pad arpeggiator, a scratcher, a modulation matrix with two LFOs, and a shared master FX chain with a four-band EQ and four insert effects.

Pads are triggered exclusively via MIDI: from the piano roll, a keyboard, or pad controllers. Two trigger modes can be mixed freely — a Drum Kit mode listening on channel 1 with a General-MIDI note map, and a Multitrack mode where each pad owns its own MIDI channel and plays tonally with keytrack.

Highlights

  • 16 pads × 2 sample slots, crossfaded, reverse, start / random offset, sample delay, phase invert
  • 64-voice engine, per-pad voice limiting and choke (killnote)
  • Amp / filter / pitch envelopes, loop editor with ping-pong and crossfade
  • 8-row modulation matrix, 2 LFOs, mod envelope, velocity curves
  • Per-pad arpeggiator with shuffle and tempo sync; scratcher
  • Master 4-band EQ + 12 insert effect types with tempo-syncable delay
  • 8 parameter banks, per-pad undo, full MIDI Learn via REAPER automation

Requirements

  • REAPER 7.x (developed and tested on 7.79) — any platform that runs JSFX
  • No third-party libraries, no binaries — everything is one .jsfx text file
  • Your own WAV/AIFF samples, arranged in kit folders (see §06)
  • Two optional Lua helper scripts for kit loading and bank saving (§02)
TT-PHALYX is the drum sibling of the TT-303 Acid Machine: core black panel, acid green (#39FF14) on ink, monospaced type, 45° circuit traces. If you know the TT-303, every widget behaves the same way.

02Installation

Files

FileLocationPurpose
tt-phalyx.jsfx…/REAPER/Effects/TimTechlor/TT-PHALYX/ The instrument. REAPER scans the Effects folder — the FX appears as JS: TimTechlor/TT-PHALYX/tt-phalyx.
TT-PHALYX Load Kit.lua…/REAPER/Scripts/ Kit loader — spreads a folder of WAVs across the 16 pads (§06).
TT-PHALYX Save Bank.lua…/REAPER/Scripts/ Bank saver — writes the complete state to a bank file (§17).

Steps

  1. Copy tt-phalyx.jsfx into the Effects folder as shown above (create the folder if needed).
  2. In REAPER, open View → FX Browser, find JS: TimTechlor/TT-PHALYX/tt-phalyx and drop it on a track. If it does not appear, run FX Browser → Rescan.
  3. Copy both Lua scripts into the Scripts folder. In REAPER: Actions → Show action list → New action → Load ReaScript… and pick each file once. They then run as normal actions.
The JSFX source is plain text. If you open it in the JSFX editor (click the Edit button in the FX window) and save, REAPER hot-reloads the plugin instantly — the UI is the compiled result of what you see.

03Quick Start

  1. Insert TT-PHALYX on an empty track. Set the track's MIDI input to your controller or to All channels.
  2. Run the Load Kit action. Pick any WAV from a folder that holds your drum samples — the folder's contents are sorted and spread across the 16 pads automatically.
  3. Play. Kit mode listens on MIDI channel 1 with the GM map (C2 = 36 kick, D2 = 38 snare, F#2 = 42 closed hat …). The kit note of each pad is printed under its waveform.
  4. Click a pad to select it — the full panel below now edits that pad. Turn TRANSPOSE, draw the amp envelope in the AMP tab, or add a delay in the FX tab.
  5. When your kit sounds right, run the Bank speichern action and store it in slot 1–8 so any project can recall it (§17).

05The Front Panel

Slim pads (top row)

Each of the 16 pads shows, from top to bottom: pad number, name, its vertical waveform and the volume fader, the kit note / MIDI channel label, and the M/S buttons.

  • Waveform — bright line: Sample A. A dark ghost contour behind it is Sample B (drawn as soon as slot B holds a sample).
  • M / S — mute / solo the pad. Soloing one pad mutes all others.
  • Fader — pad volume, 0–100 % (default 80 %).
  • LED (top right) — lights while voices of this pad are sounding.
  • Small bar (left of the LED) — arp marker; lit while this pad's arpeggiator is running.
  • Bottom label — kit note in drum mode (K:C2) or MIDI channel in multitrack mode.

Full panel (selected pad)

The row of buttons on the left switches which sample slot the two knob rows edit:

A / B
Select slot A or slot B as the edit target. The front waveform always shows both.
A -> B
Copy all slot-A settings and the sample assignment to slot B.
PHASE
Invert the polarity of the selected slot — useful to fight phase cancellation between A and B.
REV
Play the selected slot backwards.
SCR
Arm the scratcher for this pad (§15).
Crossfade fader
Mix slot A and B. 0 %= A only, 100 %= B only. The XFADE target of the mod matrix rides this fader.

Start point of playback, 0–100 % of the sample.

INPUT box (right side)

KILLNOTE
Choke group of one: a new note-on with this note number stops the pad (classic closed-hat-kills-open-hat). −1 = off.

Per-pad voice limit, 1–16. Oldest voice is stolen first.

Base note for multitrack keytrack and the arpeggiator, 0–127 (default 36).

Pitch-bend range in semitones, 0–24 (default 2). Bend is slewed (~11 ms) for a smooth, analogue-style glide and applies to all playing voices of the pad.

The header shows active voices against the polyphony limit, the project tempo, and the CLIP LED — it lights when the output stage exceeds 0.95 and decays after the overload.

06Loading Kits

JSFX cannot open file dialogs, so samples arrive through a kit file. The Lua action “TT-PHALYX Load Kit” builds it:

  1. Run the action. A file dialog opens — pick any WAV inside your kit folder.
  2. The script lists the folder, sorts it alphabetically, and writes tt-phalyx-kit.bin: entries 1–16 become Sample A of pads 1–16, entries 17–32 become Sample B. A readable tt-phalyx-kit.txt documents the mapping.
  3. The plugin polls the kit file about twice per second and reloads any slot whose path changed — new kit takes effect without restarting.
Name your files with numeric prefixes (01_kick.wav, 02_snare.wav …) to control the sort order. Subfolders are ignored. To audition a single new snare, drop it alone in a folder and load — the rest of your banks/parameters stay untouched because only samples move, not parameters.
Projects store the parameter state and the kit paths, never the audio. Keep kit folders in a stable location; if a WAV moves, its slot loads empty.

07AMP Tab

The amp envelope is drawn as breakpoints over the sample waveform of the selected slot. Drag the points to shape attack, decay, sustain and release stages; the horizontal axis is controlled by TIMESCALE — below 100 % the envelope runs faster than drawn, above 100 % slower. Timescale also applies to the filter envelope.

  • One-shot pads ignore note-off and run the envelope to the end of the sample.
  • Sustain pads hold at the sustain level until note-off, then release.
  • RETRIG adds keytrack and fade behaviour for fast repeated notes — useful for rolls without clicking.
  • ENV → INIT (front panel) restores the drum defaults of all envelopes of the pad.

The overview screenshot in §04 shows the AMP editor with its envelope points over the pad's waveform.

10FX Tab

The FX tab is the shared master chain, identical for all pads: 4-band EQ → insert 1 → insert 2 → insert 3 → insert 4. Each insert slot can host one of twelve effect types with four parameters and a mix control; OFF bypasses the slot.

Four-band EQ

  • Bands: PEAK, LO-SHELF, HI-SHELF, LO-CUT, HI-CUT — click a band's type to step forward, right-click to step back.
  • Frequency 30 Hz – 20 kHz (logarithmic), gain ±15 dB, Q 0.3 – 8.
  • The response curve is drawn live and updates while you drag.

Every slot has its own MIX knob (dry/wet). CHORUS uses two modulation voices per channel (v1.02) — noticeably fuller than a single-voice chorus. ROOM is a dense algorithmic room, TRASH a degraded “zero verb”, GATE a gated reverb — all three accept a predelay on P4 to keep transients in front of the wash.

Tempo sync for the delay

With SYNC (SYSTEM tab) set to DELAY or DELAY+ARP, the DELAY TIME parameter selects a note value instead of milliseconds:

TIME position01234567
Note value1/161/8T1/81/4T1/41/23/41/1

The value row of the slot shows the note name while sync is active. The delay buffer holds 1 s per channel at 96 kHz — very long values at low tempos are clipped to the buffer length. Value changes are stepped, not ramped; retrigger a hit if you change the raster mid-groove.

11LOOP Tab

The loop editor works on the selected slot (A or B — choose it in the full panel).

Flags
Drag the start and end flags directly in the waveform. The loop runs between them while LOOP is on.
NRM
Normal loop: end jumps back to start.
PING
Ping-pong: alternates forward and backward passes.
XFD
Crossfaded loop: the tail of the loop is blended into the start to hide the seam.
ZERO
Snaps the flags to the nearest zero crossings — loops without DC thumps.
XFADE ms
Length of the loop crossfade in milliseconds.
Loop points follow the sample: they are stored as permille of the loaded sample, so a re-scan of a slightly edited file keeps its loop roughly in place.

13MIDI/ARP Tab

Drumkit matrix

A one-and-a-half-octave keyboard shows the current kit mapping. Click any key to assign it to the selected pad (drum mode only — multitrack pads use channels instead). The mapping is per pad and stored with the project.

Arpeggiator — one per pad

Hold a note and the pad's arp takes over, firing sample-accurately in the audio thread (no plugin-latency wobble):

MODE
OFF, UP, DOWN, UP-DN (up-down), RND (random octave), ROLL (retrigger wall on the base note — hat rolls). Right-click steps back.
RATE
20 ms … 2 s (quadratic). With ARP tempo sync: 1/4, 1/8T, 1/8, 1/16T, 1/16, 1/32 — the value display shows the note name.
OCTAVES
1–4 octaves above the held note.
GATE
Step length 5–100 % of the rate — shorter values leave audible gaps.
SHUFFLE
0–50 %. Off-beat steps swing late while the grid itself stays put — 50 % turns straight sixteenths into a full swing feel. Drag the number directly.

The slim pads show a small arp marker while a pad's arpeggiator runs. A note-off stops that pad's arp; the current step still plays out.

15Scratcher

  1. Arm the pad with SCR in the full panel.
  2. Hold a note on that pad.
  3. Grab the waveform in the full panel and drag — the playhead of both slots follows your hand, like a vinyl scratch, for as long as the note is held.

The same position is exposed as automation slider 53, so you can scratch from a MIDI controller, an LFO in REAPER's modulation system, or draw scratch moves in the arrange view. A playhead line on the waveform shows the live position.

Multitrack mode

Pad input 1–16 assigns the pad exclusively to that MIDI channel. The pad becomes tonal: incoming notes are tracked relative to ROOT and transposed with TRANSPOSE/FINE — play chromatic lines through one pad's sample. Different pads can share a channel (layering) or split the channels.

Other MIDI behaviour

  • Incoming transpose (SYSTEM, ±24 st) is applied first; in kit mode it remaps the entire kit.
  • Pitch bend applies to all sounding voices of a pad within the pad's PB range (0–24 st, default 2), smoothed over ~11 ms.
  • Killnote implements per-pad chokes; the classic use is closed hat (42) killing open hat (46): set the open-hat pad's killnote to 42.
  • Monitor: the status line at the bottom logs note events, shows the last pitch-bend / CC values and a velocity bar for each of the 16 pads.
  • TT-PHALYX consumes note events; CC and pitch bend are passed through the FX chain.

17Banks & Undo

A bank is the complete state of the plugin — all 16 pads with every parameter, the mod matrix, envelopes, the master EQ and FX chain, polyphony and system settings. Samples always come from the current kit, so a bank is a sound-setup snapshot, not an audio archive.

Save (Lua action)

  1. Set up your kit and parameters.
  2. Run “TT-PHALYX Save Bank”.
  3. Enter a slot number 1–8. The action saves tt-phalyx-bankN.bin next to the plugin.

Load (SYSTEM tab)

  1. Click B1…B8.
  2. The bank replaces parameters and FX; the status line confirms “BANK LOADED” or “BANK EMPTY OR WRONG VERSION” (empty/incompatible).

Undo

  • SNAP stores the selected pad's parameters; UNDO restores them. One level per pad.
  • Switching pads takes an automatic snapshot — a quick UNDO always brings back what you just left.

19Limitations vs. Phalanx

TT-PHALYX follows Phalanx where JSFX allows it. These points are deliberate differences:

PhalanxTT-PHALYX
16 stereo outputs1 stereo output (JSFX limitation). Workaround: several instances on routed tracks.
256 voices64 global voices, 1–16 per pad — far beyond drum needs.
AA Reverb & impulse convolutionAlgorithmic ROOM/TRASH/GATE instead — no convolution in JSFX at real-time-friendly cost.
Vengeance plugin hostingNot possible in JSFX.
Samples embedded in the projectSamples referenced from kit folders; projects store paths and parameters (keeps projects small and REAPER-native).
Banks saved from the UILoad from the UI; saving via the bundled Lua action (JSFX file access is read-only).
Drag & drop sample loadingKit-folder loading via the Lua action.

20Troubleshooting

No sound?

  • Kit not loaded — run the kit action and check the pad labels for file names.
  • Kit mode listens on channel 1 only; set the track input or the pads to multitrack channels.
  • Mute/solo state: a lone active SOLO silences every other pad.
  • Check pad volume (default 80 %) and master volume (default 90 %), and the CLIP/MUTE LED column — a red CLIP indicates earlier overload.

FX window shows an error text instead of the UI

The JSFX failed to compile (e.g. after a manual edit). The first line names the problem; fix or restore tt-phalyx.jsfx — REAPER recompiles on save.

Sync / banks oddities

  • Delay ignores sync — set SYSTEM → SYNC to DELAY or DLY+ARP; the delay TIME row must then show note values, not ms.
  • Arp plays ms again — same switch; ARP must be active in SYNC.
  • “BANK EMPTY OR WRONG VERSION” — the bank file doesn't exist or was written by an incompatible version. Re-save it with the current Lua script.
  • First ~0.5 s after loading ignore the FX preset file — the plugin polls external config files on a timer; renders starting at zero should place hits beyond the first half second.

Sound & CPU

  • Clicks when transposing up — switch the pad to AA (Hermite) interpolation.
  • Samples longer than 20 s are truncated per slot (loop material is unaffected in principle — but plan loops below 20 s).
  • CPU: the arpeggiator scheduler sleeps when no arp is active; AA interpolation and the ROOM insert are the most expensive blocks per voice.
